# CredLink — Unified Life-Stage Digital Identity & Record Network

CredLink is a cross-domain digital identity and verifiable credential platform serving citizens, educational institutions, financial entities, healthcare providers, employers, and network administrators.

## Project Architecture
- `apps/web`: Next.js App Router Frontend Portal
- `packages/shared-types`: Unified TypeScript Domain Contracts
- `packages/api-client`: Abstract API Client interfaces
- `packages/validation`: Credential and verification schemas

## Getting Started
```bash
# Install dependencies
npx pnpm install

# Run dev server
npx pnpm dev
```
